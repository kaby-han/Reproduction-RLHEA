# Reproduction-RLHEA
Reproduction of an essey about the reinforcement learning guided hybrid evolutionary algorithm

文献引用：Yuji Zou,Jin-Kao Hao,Qinghua Wu.A reinforcement learning guided hybrid evolutionary algorithm for the latency location routing problem[J].Computers & operations research,2024,170,DOI:10.1016/j.cor.2024.106758.

作者提供的项目代码“g++ 10.2.1 on Linux”及其数据集和获得的最优解：https://github.com/YujiZou/LLRP

本项目是本人九个月前，本科三年级上学期，断断续续花费三个月完成的论文复现。
代码只实验过部分作者提供的数据集，且没有与作者的最好解进行比对。

当时复现这篇文献主要有两个原因：一方面是了解机器学习、强化学习等方法在运筹优化领域的应用；另一方面是锻炼代码能力。代码是用python语言，按照面向过程的方式编写的，复现过程让我对LNS、搜索算子有新认识，也让我接触和应用了强化学习方法。幽默的是现在ai代码编程能力太强，我刚学会了手搓编程，就被vibe coding取代了，直接变成古法编程退出历史舞台。

第一次创建GitHub仓库好激动，先前都是在不断搜索和学习大佬们开源的程序代码，代码的强化学习部分就是参照前人开源的GitHub强化学习项目学会的。在GitHub上公开我拙劣的、笨拙的、繁琐的代码算是给我自己留作一个纪念吧，当时自己摸索、试错的时光又痛苦又好玩。
